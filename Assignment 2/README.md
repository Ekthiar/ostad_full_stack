# Python Assignment

This repository contains two Python programs completed as part of the Python assignment.

## 📁 Programs

### 1. Simple Function

**File:** `problem1.py`

This program:

* Defines a function named `greet()`
* Takes a person's name as a parameter
* Prints a greeting message using the name
* Calls the function with user input

---

### 2. Simple File Writing

**File:** `problem2.py`

This program:

* Takes the user's name as input
* Opens a file named `name.txt`
* Writes the name into the file
* Closes the file automatically using `with open`

## ▶️ How to Run

Make sure Python is installed on your computer.

Run the programs using:

```bash
python problem1.py
```

```bash
python problem2.py
```

## 🛠️ Technologies

* Python 3
* Functions (`def`)
* File Handling (`open()`, `write()`)
* Standard Input/Output (`input()`, `print()`)
* f-strings

# Python Assignment

This repository contains two Python programs completed as part of the Python assignment.

## 📁 Programs

### 1. Student Grade Calculator

**File:** `student_grade_calculator.py`

This program:

* Takes a student's name as input
* Takes marks for 3 subjects
* Calculates total marks
* Calculates average marks
* Determines the grade based on the average

### Grade Criteria

| Average Marks | Grade |
| ------------- | ----- |
| 80–100        | A+    |
| 70–79         | A     |
| 60–69         | B     |
| 50–59         | C     |
| Below 50      | F     |

---

### 2. Simple Shopping Cart

**File:** `shopping_cart.py`

This program:

* Takes the customer's name as input
* Takes the names and prices of 3 products
* Calculates the subtotal
* Calculates the discount
* Calculates the final total
* Displays the shopping summary

### Discount Criteria

| Subtotal      |    Discount |
| ------------- | ----------: |
| 5000 or above |         20% |
| 3000–4999     |         10% |
| 1000–2999     |          5% |
| Below 1000    | No discount |

### Formulas

```text
Discount = Subtotal × Discount Rate
Final Total = Subtotal - Discount
```

## ▶️ How to Run

Make sure Python is installed on your computer.

Run the programs using:

```bash
python student_grade_calculator.py
```

```bash
python shopping_cart.py
```
